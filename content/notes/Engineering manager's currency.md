Manager's main currencies are
- attention a manager gives to the reports; 
- interesting tasks a manager assigns. 

It might feel that it's the same thing, an interesting task being a type of attention. It's only partially true, as assigning a task means thinking of an assignee, therefore attention. But the difference is that a task as currency has different value to different reports.
